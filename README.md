# tvcast-launcher

`tvcast.js` is the phone-side code of tvcast, a personal tool for casting web video to a TV. A
small "tvcast" bookmark loads it from here each time it is tapped, so the bookmark never needs
updating.

This file is generated from `extension/bookmarklet.js` in the main tvcast repo
(`python3 tvdevice.py launcher-code`). Don't edit it here. It contains no keys or settings: the
bookmark supplies those when it runs.
